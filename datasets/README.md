# Tracked study reports

This directory contains compact, explicitly approved study reports suitable
for Git history. Raw solver node exports remain under ignored `output/` and
must not be committed unless the user explicitly requests them.

For STU002 and STU004, `analysis/strategy-10/` is the active
machine-readable strategy output. The single `<STU>_flop_strategy.xlsx` file
at each analysis root is the active human table. Superseded category layouts,
clustering and smoothing experiments, and the superseded STU003 pilot dataset
are intentionally absent.
