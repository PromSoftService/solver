# Tracked study reports

This directory contains compact, explicitly approved study reports suitable
for Git history. Raw solver node exports remain under ignored `output/` and
must not be committed unless the user explicitly requests them.

For STU002, `analysis/strategy-13/` and `analysis/strategy-8/` are the active
machine-readable strategy outputs. The two `.xlsx` files at the STU002 analysis
root are the active human tables. Superseded clustering and smoothing
experiments are intentionally absent.
