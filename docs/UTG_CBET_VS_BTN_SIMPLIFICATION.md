# Approved STU004 UTG c-bet simplification

## Scope

This is the approved manual teaching table for `STU004 / 01_UTG_FIRST`:
UTG acts first against BTN and chooses CHECK or BET one half-pot. It was
reviewed from the tracked combo/action-EV export and is not generated by a
repository script.

Classifier priority remains OESD, Gutshot, made hand,
`2 overcards + BDFD`, then Air. The production generator, canonical workbook,
trainer and active STU005 solve were not changed.

## Flop classes

The three mutually exclusive classes contain all 286 study boards:

- `AKx / Kxx`: 66 boards, meaning A-high containing K or any K-high board;
- `[A/Q/J]xx`: 136 other A-high, Q-high or J-high boards;
- `[T-4]x`: 84 boards with top rank T through 4.

subgroup is an accepted exception whose root contribution is negligible.
