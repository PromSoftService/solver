# Approved STU002 UTG c-bet simplification

## Scope

This is the approved manual teaching table for `STU002 / 02_UTG_AFTER_CHECK`:
BB checks and UTG chooses CHECK or BET one half-pot. It was reviewed from the
tracked combo/action-EV export. It is not generated by a repository script.

Classifier priority remains OESD, Gutshot, made hand,
`2 overcards + BDFD`, then Air. The active STU005 solve, production generator,
canonical workbook and trainer were not changed.

## Flop classes

The four mutually exclusive classes contain all 286 study boards:

- `A-high`: 66 boards;
- `K/Q-high`: 100 boards;
- `J/T-high`: 64 boards;
- `9-high and lower`: 56 boards.

The extra column is retained because Low pocket pair is active on J/T-high but
the solver BET frequency is approximately zero on 9-high and lower. It also
allows Overpair to pure-bet J/T-high while retaining B/X on the lowest boards.

Deliberate reach-weighted row deviations are Underpair +9.1 pp, Weak pair
-11.5 pp, Gutshot +9.5 pp and `2 overcards + BDFD` +8.2 pp. Weak pair remains
pure CHECK outside A-high because random B15 policies selected the wrong weak
hands and increased fixed-opponent loss. OESD retains B/X only on K/Q-high:
pure BET improved local fixed-opponent EV but overbet the complete OESD row by
about 21 pp, violating the range-composition objective.

GPT-6 Astra independently preferred the four-class split. Its proposed B15
cells were reproduced locally and rejected where tracked action EV showed that
the randomizer selected the wrong combos. Local tracked data remains decisive.
